# Developer Salary Prediction Model (2025)

## Project Overview

This project involves development of a machine learning model to predict annual salaries of technology professionals using data from the 2025 Stack Overflow Developer Survey. The dataset contains responses from developers and other technology professionals across multiple countries, capturing information on professional experience, employment characteristics, technologies used, years of work experience and compensation.

To improve model performance and focus on the most representative markets, the analysis was restricted to the top 15 countries with the highest number of survey responses.

The project follows a complete machine learning workflow, including data preprocessing, exploratory data analysis (EDA), feature engineering, model training, evaluation, and deployment through a Flask web application.

## Business Problem

Technology salaries vary significantly across countries, experience levels, and professional backgrounds. Organizations, recruiters, and professionals often require reliable salary estimates to support compensation planning and career decisions.

The objective of this project is to build a predictive model capable of estimating a developer's annual salary based on demographic, geographic, and professional attributes.

## Model Optimization & Feature Engineering

Several iterations of feature engineering and model tuning were performed to improve predictive performance.

### Feature Expansion

The initial model was trained using a limited set of features. To capture more information from the dataset and improve predictive accuracy, the feature set was expanded to include 15 key variables describing:

* Geographic location
* Professional experience
* Employment characteristics
* Educational background
* Developer profile attributes

The additional features allowed the model to better capture salary variations across different countries and professional groups.

### Target Variable Transformation

Exploratory Data Analysis revealed that salary data exhibited a strong right-skewed distribution, with a small number of respondents reporting exceptionally high salaries.

To address this issue, a logarithmic transformation was applied to the target variable (annual salary). This transformation:

* Reduced the impact of extreme outliers
* Improved the normality of the target distribution
* Stabilized variance
* Enhanced model learning and generalization

Predictions were transformed back to the original salary scale using the exponential function for interpretation.

### XGBoost Hyperparameter Tuning

The XGBoost Regressor was further optimized by adjusting key hyperparameters, including:

* Number of estimators
* Maximum tree depth
* Learning rate
* Subsample ratio
* Column sampling ratio
* Regularization parameters

These adjustments improved the model's ability to balance bias and variance while reducing overfitting.

### Performance Improvements

The combination of:

* Expanded feature engineering
* Log transformation of the target variable
* XGBoost hyperparameter tuning

resulted in improved predictive performance compared to the baseline model and earlier iterations.
